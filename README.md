# 美国家庭万用亲子英语 8000 句 · PWA

中英对照的亲子英语口语句子，做成可以安装到手机上的离线网页应用（PWA）。

- 英文在上（加粗），中文在下（小字）
- 47 章、406 个小节、7479 句，全部重新校对过中英文
- 点击句子用系统语音朗读英文，右下角按钮可连续朗读整节
- 中文可设为“显示 / 点击显示 / 隐藏”，方便自测
- 全文搜索（中英文均可）、收藏、记住上次阅读位置
- 字号可调，支持深色模式，断网可用

## 安装到手机

打开 GitHub Pages 网址后：

- **iPhone（Safari）**：点底部“分享”按钮 → “添加到主屏幕”
- **Android（Chrome）**：点右上角菜单 → “安装应用” 或 “添加到主屏幕”

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` / `style.css` / `app.js` | 应用界面 |
| `data.json` | 全部句子（按章节组织） |
| `sw.js` | Service Worker，负责离线缓存 |
| `manifest.webmanifest` | PWA 安装信息与图标 |

更新内容后，把 `sw.js` 里的 `VERSION` 改一下（例如 `fe-v2`），已安装的手机就会自动拿到新版本。
